Exact regime and controls
-------------------------
65,536 lanes, 16 bounded steps, WORK=128 dependent u64 ALU rounds, four
interleaved depths 16/14/12/10, and A/B mixed at every live epoch. The exact
frame schema is 280 bytes: u32 remaining, u32 next class, u64 accumulator, two
u32 class flags, and 32 u64 state words. On every live step every handler,
including the competent generic and one-class specialized handler, generates a
load, nonzero add (field indices 5..36), and store for every added u64. Initial
state depends on lane and field. This is executable state, not padding.

The independently evaluated CPU oracle covers the entire frame and canonical
trace. All 72 measured rows (and warmups) assert exact complete frames and
canonical traces for grouped width 32, competent one-submit generic persistent
worker, grouped width 1, 16-submit level sync, and eight sequential frozen-chunk
"low arrival". Chunk traces are lane-rebased and canonically sorted before the
full comparison. The specialized one-class API is checked against its full CPU
ResidentFrameGraphResult: frames, accesses, operation journals, and canonical
trace. Oracle hashes (canonical little-endian trace fields) are:
  mixed final frames: f946425b13a7dbd009d6901bf8eb1e7237460c7b594aa1a77cb87458175b1b7b
  mixed dynamic trace: 207e6ae087197b058da4b1d371433c03dceeb81f8e97bfb4df200d42ed4001ef
  one-class final frames: 36d35fbd1d77edd9087383eb9d9e3caf24cee2c41a36e79881fa62b900a74f93
  one-class canonical trace: 1693a6214476ff4a9d5e520829dd6114df2208a4d42836f254b6432c1a5390e0

Each process has three recreated-backend batches, two warmups per batch, and 12
samples. Grouped/generic order is AB/BA balanced (six observations in each call
position per batch); a common 25 ms pre-pair cooldown is used. All measured GPU
calls qualify above 20 ms: minima grouped 60.175 ms, generic 59.513 ms, width-1
58.379 ms, one-class 31.019 ms, level-sync 100.904 ms, low-arrival 67.408 ms.
Timings include allocation, encoding, submission/wait, and final readback.
Controls follow the balanced primary pair and therefore their ratios below are
descriptive controls, not separately call-position-randomized causal estimates.
