This epoch

Every ant is its own process, choosing its own next behaviour and knowing about no other ant. SOMA packs the ants about to run the same behaviour into one SIMD dispatch. Switching scheduler reruns the identical colony — the world never changes by a single ant, only how the machine packs it. predator takes an entire colony at epoch 150: the failure stays there and the other ninety-nine keep foraging.
Lane occupancy is a structural quantity, computed from how continuations group — a lane group spanning k run classes is charged k masked dispatches because a uniform-dispatch executive cannot do better. The reference executive runs a cohort's lanes one after another, so nothing here is a wall-clock measurement.
